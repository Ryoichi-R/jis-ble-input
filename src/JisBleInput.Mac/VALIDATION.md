# 0.20.0（ビルド29）の検証

2026-11-16 JST。0.19.0からMacの送信範囲を英数字・URLに限定した。日本語の選択肢は無効で、本文の変換経路、診断画面、試し打ち、試験速度は製品用アプリから除いた。

- `zsh build.sh` で製品用のアプリを作成し、署名と版を確認した。画面検証は `zsh build.sh --check-ui` で生成した別アプリを使用した。
- `zsh checks/run-key-parity.sh` で、JISとUSの半角ASCII、改行、3つの速度、5,000文字上限・文字数の数え方をWindows版と比較し、583行が一致した。
- `zsh checks/run-safety.sh` で旧日本語設定、非ASCII文字、5,001文字の送信拒否と、5,000文字・CRLFの受付、CapsLockと全キー解放の制御、旧定型文の保持を確認した。
- 画面検証では日本語メニューの無効化、旧設定でのボタン・⌘Return・続行の送信抑止、英数字送信、接続の中断、スリープ復帰、定型文を確認した。
- ZIPを展開して、SHA-256、アプリの署名、版、製品用実行ファイルを照合した。対象フォルダーの formatter と Fast lint に合格。

0.20.0のWindows実機接続・受信は未確認。
